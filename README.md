# Canteen App Android

Aplikasi Android simulasi kantin digital untuk menampilkan menu makanan, detail produk, dan proses pemesanan sederhana.

## ✨ Features

* Menampilkan daftar menu makanan
* Detail produk makanan
* Tampilan berbasis RecyclerView
* UI Android modern
* Simulasi pemesanan makanan
* Responsive mobile interface

## 🛠 Tech Stack

* Kotlin
* Android Studio
* XML Layout
* RecyclerView
* Material Design Components

## 🚀 Installation

1. Clone repository

```bash
git clone https://github.com/jaqckline/canteen-app-android.git
```

2. Open project in Android Studio

3. Sync Gradle

4. Run application on emulator or Android device

## 📌 Purpose

Project ini dikembangkan sebagai aplikasi Android sederhana untuk mempelajari pengelolaan data menu makanan dan implementasi UI mobile menggunakan Kotlin.
